Referências e fontes

Esta página registra os recursos externos consultados e os elementos originais desenvolvidos para o projeto.

Conteúdo e desenvolvimento

O conceito, a estrutura do site, a identidade visual, os textos institucionais e as ilustrações SVG utilizadas neste projeto foram desenvolvidos especificamente para a proposta acadêmica AloCare.

Recursos técnicos consultados

  • MDN Web Docs — HTML — referência para estrutura e elementos HTML.
  • MDN Web Docs — CSS — referência para estilos e layout responsivo.
  • MDN Web Docs — JavaScript — referência para DOM, eventos, arrays, objetos e armazenamento local.
  • Chrome DevTools — CSS Overview — recurso indicado para análise de CSS e contraste.
  • Chrome Lighthouse — recurso para testes de desempenho, acessibilidade, melhores práticas e SEO.
  • W3C Markup Validation Service — validação da marcação HTML.
  • W3C CSS Validation Service — validação dos arquivos CSS.

Imagens

As ilustrações utilizadas no site foram criadas como arquivos SVG originais para este projeto, sem uso de modelos de terceiros.

Observação acadêmica

O AloCare é um projeto acadêmico desenvolvido para demonstrar competências de HTML, CSS e JavaScript no curso WDD 131. As informações de contato exibidas são demonstrativas.
